# Social Hub

A small installable web-app launchpad for YouTube and Instagram.

## Run it

Publish this repository with GitHub Pages:
1. Open the repository's **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then Save.
5. Wait for the Pages URL to appear on the Pages settings screen.

## What it does

- Opens the official YouTube and Instagram websites.
- Sends a search query to YouTube's official search page.
- Includes a web-app manifest and a small service worker for the app shell.

## Important limitations

This is a web app, not a native Android app or an embedded copy of Instagram/YouTube. The official services still handle sign-in, content, and playback. It cannot bypass browser, school/device, account, or network restrictions.
